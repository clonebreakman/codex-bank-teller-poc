# 阶段 B 签署包：内部柜员副驾驶 PoC

**文档状态：** 待负责人审查与签署  
**适用范围：** 本地合成环境中的内部柜员副驾驶切片  
**当前结论：** 技术闸门通过，业务、安全、工程和合规签署尚未完成

## 1. 签署目的

本签署包用于确认阶段 B 是否可以继续保持在“内部柜员辅助、合成数据、只读 / 审查动作、本地隔离环境”范围内进行后续工作。

签署不代表：

- 可以连接真实银行核心系统；
- 可以处理真实客户、真实账户或真实凭据；
- 可以执行转账、开户、改密、销户、贷款审批、现金处理或其他金融写操作；
- 可以把 Computer Use 或模型输出作为最终金融责任主体；
- 可以跳过 P8、P9 各自的设计、测试、合规和发布闸门。

## 2. 阶段 B 范围

阶段 B 只覆盖以下本地合成能力：

- 展示合成客户上下文、建议动作、风险等级、策略决定、验证状态、制度引用和审计引用；
- 支持柜员明确执行「确认」「修改」「转人工」「拒绝」四类审查动作；
- `confirm` 必须同时满足 `policyDecision=allow` 和 `verificationStatus=verified`；
- 服务端按 `runId` 串行动作，避免并发重复确认；
- 所有动作返回 `executed: false`；
- 每个动作写入追加式合成审计事件；
- 服务只绑定 `127.0.0.1`；
- Playwright 只使用临时无头浏览器和随机回环端口；
- Browser Harness 拒绝外部域名和未登记动作。

## 4. 负责人评审问题

### 4.1 业务负责人

请确认：

- 四类柜员动作的业务含义和终态是否清楚；
- 「转人工」是否保留足够的上下文，且不会被误认为业务已完成；
- 「修改」是否必须填写理由，以及当前摘要形式是否满足复核需要；
- 页面展示的风险、策略、验证和制度来源是否足以支持柜员判断；
- 当前只支持内部合成案例，是否符合阶段 B 的业务范围。

### 4.2 安全负责人

请确认：

- 服务运行时固定绑定 `127.0.0.1` 的边界是否足够；
- 合成数据标记、非合成 actor 拒绝和 16 KB 请求体限制是否满足本地 PoC 要求；
- 未知字段、未知动作、未知案例和外部域名拒绝是否覆盖主要攻击面；
- 审计日志中的 `actorId`、修改说明哈希和长度是否满足追责与脱敏要求；
- Playwright 临时浏览器不复用用户 Profile、Cookie、凭据和剪贴板的限制是否清楚。

### 4.3 工程负责人

请确认：

- README 中的安装、测试和清理命令能否在干净环境复现；
- Playwright 依赖、Chromium 版本和本地临时资源的生命周期是否可维护；
- 当前提交范围、测试证据和回滚方式是否足够；
- P7.2 技术通过后仍禁止进入 P8，是否符合发布流程；
- 后续 P8 是否必须另行设计、评审和验收。

### 4.4 合规与内审

请确认：

- 阶段 B 的范围没有使用真实客户、真实凭据或真实资金；
- 当前技术通过记录不会被解释为生产授权或金融业务批准；
- 进入 P8 前需要补充的身份、数据驻留、访问控制、投诉和人工接管要求；
- 是否需要保存本签署包、测试输出和审计样例作为评审材料。

## 5. 自动否决条件

出现以下任一情况，阶段 B 不得签署通过：

- 发现真实客户数据、真实账号、密码、OTP、PIN、CVV 或支付信息进入仓库或测试日志；
- 服务能够绑定到非 `127.0.0.1` 地址；
- 未经柜员动作就出现审查成功或金融工具调用；
- `executed` 不为 `false`，或审计事件缺失、不可追溯或包含修改说明明文；
- 并发重复动作产生多个成功结果；
- 外部域名、未登记动作或未知字段可以绕过网关；
- 测试、Lint、TypeScript 或安全检查不能稳定复现通过；
- 任何人将本阶段技术通过解释为真实银行接入授权。

## 7. 进入 P8 的前置条件

只有在上述签署完成且没有未关闭的阻断项后，才可以开始 P8 设计审查。P8 仍必须继续使用合成数据，并至少单独验证：

- 合成身份和会话绑定；
- 会话过期、账户不匹配和异常频率；
- 客户、账户和交易字段脱敏；
- 限流、转人工和投诉入口；
- 未认证或高风险会话不得自动完成服务；
- 不执行任何真实金融写操作。
