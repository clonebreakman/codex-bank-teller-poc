一句话结论

PoC 证明了低风险只读、隔离 GUI、策略控制、外部验证和柜员审查的技术闭环；没有证明、也不宣称具备完全自动化柜面服务或进入真实银行生产环境的资格。

01 / Workflow

一条请求，经过 5 道可审查关口

模型不直接拥有金融权限。每一步都把自由度收窄，把事实和责任放回确定性服务与人工。

01

意图与 run_id

接收指令，生成唯一运行编号，建立可追踪上下文。

02

工作流注册

只选择登记过的流程、输入 schema、工具和验证器。

03

策略与工具网关

判断 allow / confirm / handoff / deny，重检参数与外域。

04

隔离执行

调用 Mock Bank 或本地 Browser Harness，不触碰真实系统。

05

验证与审计

外部验证最终状态，脱敏、记录、回放，异常转人工。

02 / Architecture

API 是主路，Computer Use 是受控兼容层

把视觉代理放在边界之内，而不是把核心账本、身份和审批交给点击坐标。
